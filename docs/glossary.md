# Glossary — the owner's names, which always win

The Library and the Assistant inject these when the word appears. A thing the owner has named
is never renamed by the AI; a thing he has not named gets a plain label and a *needs a name* flag.

| Term | Site | Means | Where |
|---|---|---|---|
| **Swatters** | Drone God Max | the drones that roam the site | DGM source |
| **Roamers** | JBN | the animals that roam the screen: turkey, squirrel, black cat, dog, the gecko on the Valencia listing | `components/critters/HouseRoamers.tsx`, `roamer-art.tsx` |
| **Critters** | JBN | the figures on listing cards — staff-chosen per listing, fixed in a corner, never over photos; includes the lotus and the golfer | `components/critters/ListingCritters.tsx`, `lib/critters.ts` |
| **Love Letters** | JBN | testimonials, and the collection they live in | `Admin → Letters` |
| **Marks** | studio / WebPro | a note attached to an element in the preview; Marks make a Brief | `services/marks.py`; `docs/webpro-markup.md` |
| **Brief** | studio / WebPro | the numbered list of Marks and notes a run must answer item by item | `docs/webpro-markup.md` |
| **Playbook** | all | standing rules with their *why*, injected into every prompt | studio `services/playbook.py`; site `CLAUDE.md` files |
| **Arcade / kinesthetic** | all | the owner's word for how interactivity should feel: physical verbs with immediate sensory payoff — never XP bars, quests or checklists | memory `interactive-design-taste` |
| **Board** | LodiStudios | the live front page: what is running, broken, waiting | `docs/ui-review.md` |
| **Run view** | LodiStudios | a Claude Code run rendered natively from its transcript | `docs/ui-review.md` |
| **The Assistant** | LodiStudios | the chat panel on every screen that drives the command registry and logs requests | `docs/ui-review.md` §Surface 4 |
